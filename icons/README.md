# Icon Placeholders

This directory should contain three PNG icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Creating Icons

You can create these icons using any image editor. Here are some suggestions:

### Quick Option: Use an Online Tool
1. Go to https://www.favicon-generator.org/
2. Upload your logo or create a simple icon
3. Download the generated icons
4. Rename them to icon16.png, icon48.png, and icon128.png

### Design Tips
- Use your brand colors
- Keep it simple (recognizable at small sizes)
- Suggested: A "LI" monogram or chain link symbol
- Use transparent background (PNG with alpha channel)

### Temporary Solution
For testing, you can use any 3 PNG images renamed to the correct sizes.
The extension will work even with mismatched sizes (Chrome will resize).

## Current Status
**The extension will not load without these icon files.**

Please add the three required icon files to this directory before loading the extension.
