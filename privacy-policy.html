Privacy Policy for LinkedIn Skills Importer

Last Updated: October 20, 2025

Summary: This extension does not collect, store, or share any of your data. It simply helps you extract skills from LinkedIn profiles for your own use.

Overview

LinkedIn Skills Importer is a browser extension that helps users extract skills from LinkedIn profiles. This privacy policy explains how the extension handles data.

Data Collection

We do NOT collect, store, or transmit any personal data.

The extension:

  • Only accesses LinkedIn profile pages when you explicitly click the extension icon
  • Extracts skills information temporarily in your browser's memory
  • Does NOT send any data to external servers
  • Does NOT store any data persistently in your browser
  • Does NOT track your browsing activity

How the Extension Works

  1. When you click the extension icon on a LinkedIn skills page, it reads the visible skills from the current page
  2. The extracted skills are temporarily held in memory and displayed in the extension popup
  3. You can copy the skills to your clipboard or download them as a JSON file to your computer
  4. Once you close the popup, all temporary data is cleared

Permissions Explained

The extension requests the following permissions:

  • activeTab: To access the current LinkedIn page only when you click the extension icon
  • scripting: To read skill names from the LinkedIn page's HTML structure
  • host_permissions (linkedin.com): To function on LinkedIn profile pages

Data Storage

The extension does NOT use browser storage APIs. No data is saved persistently.

Third-Party Services

The extension does NOT communicate with any third-party services or external servers. All processing happens locally in your browser.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the extension's listing on the Chrome Web Store.

Contact

For questions or concerns about this privacy policy, please open an issue on our GitHub repository.
